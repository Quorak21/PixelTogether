Mesure d’audience

Nous comptons les pages vues de façon agrégée, sans cookies publicitaires.

Session navigateur

Un jeton de reconnexion est stocké dans le localStorage du navigateur. Il sert uniquement à reprendre une partie après un rechargement ou une coupure, et est supprimé à la fin de la partie.

Données de partie

Pendant une partie, les infos (pseudos, dessins, chat…) restent sur le serveur uniquement le temps du jeu, puis sont effacées. Le détail de ce qui peut être conservé côté technique est décrit dans la documentation : Conservation des données.
